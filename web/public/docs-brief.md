# RAV Documentation Brief

RAV 2.4.3 (Rive Animation Viewer) is a desktop tool for loading `.riv` files, inspecting ViewModel inputs, and debugging animation runtime behavior. List controls retain authored item names with a readable fallback, image properties support select/decode/replace/clear, and applied editor config is preserved and executed in standalone exports.
