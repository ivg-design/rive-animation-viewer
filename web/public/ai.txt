RAV is a desktop Rive viewer for inspection, playback testing, ViewModel control,
debugging, standalone HTML and snippet generation, and rendered media export.
Desktop media formats are H.264, H.265, WebM, APNG, GIF, PNG, JPG, and WebP when
capability checks pass. See `/docs/media-export` for settings, recording, limits,
and MCP automation. Use `/changelog` only for version history.

Privacy: configured official builds enable anonymous reporting by default, show a
first-run notice before reporting, and keep the opt-out in Settings. See `/privacy`.
