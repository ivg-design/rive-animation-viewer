# RAV documentation captures

These are clean desktop-app captures prepared for the website guide. They are intentionally unframed; the website background and border treatment will be added separately.

Required views:

- `timeline-scrubber.png` — timeline-only row with frame/seconds scale and CTI.
- `export-chooser.png` — compact media versus web/code chooser.
- `timeline-export-settings.png` — timeline range, format, output, and destination controls.
- `interaction-recording-settings.png` — manual/timed state-machine recording options.
- `still-image-export-settings.png` — current/timed still options and static formats.
- `gif-size-options.png` — presets, target size policy, quality, repeat, and encoder controls.
- `export-progress-status.png` — RAV progress in the bottom status bar.
- `snippet-export-settings.png` — focused property selection and compact code preview.

Capture rules:

1. Use the built desktop RAV app, never browser RAV.
2. Use a real `.riv` file with the relevant timeline or state machine active.
3. Capture only the app window or dialog; exclude desktop clutter and other apps.
4. Keep native RAV colors and spacing. Do not add a background, border, shadow, annotation, or crop treatment.
5. Verify text, selected format, destination state, and result status before capture.
